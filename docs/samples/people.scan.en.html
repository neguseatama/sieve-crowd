  • the table is assumed to have one row per person. If the same person appears in more than one row, observe the repetition with --subject.
  • k-anonymity does not prevent matching against other information, or guessing an attribute from the values inside a group.
  • this report was produced by reading the table once; it changes nothing and writes only this page.
  • no cell value appears anywhere. The page carries column names, counts, shares, rule ids, file names and the input SHA-256 — nothing else.
  • the same input produces the same bytes every time (no clock, no environment values).
  • findings are listed in a fixed order: kind (code ascending), then column name (codepoint order), then the source order.
  • shares are computed in integer arithmetic (floored per-mille) and shown with one decimal.
  • column names longer than 120 code points are shortened for display (the draft below keeps the full names).
  • the roles are provisional — placed from the hint-pack candidates, not decided.
  • color carries no information (neutral colors only).
